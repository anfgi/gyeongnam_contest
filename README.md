# 경남케어 AI (GyeongnamCare AI)

> **경상남도 18개 시·군 도민을 위한 스마트 AI 의료 & 안심 돌봄 서비스**  
> "앱 설치도, 복잡한 본인인증도 없이 전화 한 통으로 시작되는 경남 맞춤형 원스톱 의료 케어"

---

## 🌟 서비스 개요
경남케어 AI는 노년층뿐만 아니라 **경상남도 도민 전체(시니어, 1인 가구, 다문화 가정, 의료 취약지역 주민 등)**를 대상으로 하는 통합 AI 의료 플랫폼입니다.  
스마트폰 조작이 어려운 상황에서도 일반 전화 통화로 증상을 상담받고, 경남 도내 18개 시·군의 거점 병원/약국을 추천받으며, **보호자의 휴대폰 번호로 실제 카카오톡 건강 리포트 알림**을 실시간으로 전달합니다.

---

## 🚀 주요 핵심 기능
1. **🎙️ 전화 한 통 AI 음성 상담 에이전트**
   - 별도 앱 설치나 회원가입 없이 음성 대화만으로 증상 분석 (STT/TTS 음성인식/합성)
   - 큰 글씨 실시간 자막, 고대비 모드, 음성 안내 접근성 기능 탑재
2. **🏥 경남 18개 시·군 맞춤형 의료기관 & 안심 당번약국 추천**
   - 창원, 진주, 김해, 양산, 거제, 통영, 사천, 밀양 및 농어촌 군지역(남해, 하동, 산청 등)
   - 지역별 거점 상급종합병원, 전문 클리닉, 보건진료소, 주말 당번약국 실시간 필터링
3. **💬 보호자 휴대폰 번호 입력 및 실제 카카오톡 알림톡 전송**
   - 웹사이트에 보호자(또는 본인)의 휴대폰 번호 입력 시 실제 카카오톡 메시지 전송
   - 통화 녹취 요약, 의심 질환, 추천 병원 및 원격 예약 연계 링크 발송
4. **🤝 경남 의료 취약지 안전망 연계**
   - 생활지원사, 방문간호사, 마을 이장 등 지역사회 돌봄 인력과 협력 체계 구축
5. **💊 진료 후 사후 관리 (경남 안심 복약콜)**
   - 처방약 복용 여부 및 통증 호전도 자동 추적 전화 및 가족 통보

---

## 🛠️ 기술 스택
- **Frontend**: HTML5, Vanilla CSS3 (Modern Healthcare Design System & Senior Accessibility), Vanilla JavaScript
- **Voice / AI**: Web Speech API (STT & TTS), Voice AI Simulation Engine
- **Messaging**: Kakao JavaScript SDK & Kakao Link/Share API, Vercel Serverless Function (`/api/send-kakao`)
- **Hosting & CI/CD**: Vercel Edge Network, GitHub Repository
