# 실버케어 AI (SilverCare AI) - 노년층을 위한 AI 음성 의료 & 안심 케어 서비스

> **2026년 울산 AI 해커톤 출품작**  
> **팀명**: 킴범주팀 (울산중앙고등학교)  
> **팀원**: 김범주, 김규민, 장희율 | **지도교사**: 임은성  
> **주제**: 실생활 문제해결을 위한 제품 개발  

---

## 🌟 프로젝트 개요
"앱 설치도, 본인인증도 없이 전화 한 통으로 시작되는 어르신 맞춤형 의료 돌봄 플랫폼"

질병관리청 통계 분석 결과 80세 이상 고령층의 백신 접종률 및 병원 예약률이 20~30대에 비해 급감하는 원인이 **디지털 소외 및 스마트폰 인증 장벽**에 있음을 발견하였습니다.  
이를 극복하기 위해 **Vapi AI 음성 에이전트**를 중심으로 전화 음성 상담, 맞춤형 노인 친화 병원/약국 추천, 보호자 카카오톡 안심 알림톡, 독거노인을 위한 복지 안전망 연계, 그리고 사후 복약 안부콜까지 원스톱으로 제공하는 통합 헬스케어 서비스를 구축하였습니다.

---

## 🚀 주요 기능
1. **🎙️ Vapi 기반 AI 음성 상담 에이전트**
   - 유무선 전화 통화만으로 증상 자연어 분석 (STT/TTS 및 LLM 결합)
   - 어르신을 위한 느리고 명확한 발화, 실시간 큰 글씨 자막 제공
2. **🏥 스마트 병원·약국 추천 엔진 (Flask Server & Function Tool)**
   - 승강기 완비, 휠체어 경사로, 대기 시간 등 고령 친화 시설 정보 우선 필터링
3. **💬 보호자 안심 카카오톡 알림톡 & 통합 리포트**
   - 진료 요약, AI 소견, 추천 병원 및 예약 연계 링크 자녀에게 실시간 발송
4. **🤝 독거노인·고령 1인가구 지역사회 안전망**
   - 생활지원사, 방문간호사, 마을 이장 등 복지 인력 연계 시스템
5. **💊 진료 후 사후 관리 (AI 복약 안부콜)**
   - 처방약 복용 여부 및 통증 호전도 자동 추적 전화

---

## 🛠️ 기술 스택
- **Frontend**: HTML5, Vanilla CSS3 (Healthcare Design System & Senior Accessibility), Vanilla JavaScript
- **Voice / AI**: Vapi Voice AI Agent, Web Speech API (STT/TTS)
- **Backend Architecture**: Flask Server, Function Tools, Public Healthcare API
- **Deployment**: Vercel Edge Network & GitHub CI/CD
